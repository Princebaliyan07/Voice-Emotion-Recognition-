# Voice Emotion Recognition System 🎤
A machine learning project that detects emotions from a person’s voice using speech analysis.

## About the Project
This project takes voice/audio input and predicts the emotion of the speaker.

### Emotions Detected
- Happy 😊
- Sad 😢
- Angry 😡
- Neutral 😐
- Fear 😨
- Surprise 😲

---
## Features

- Voice input processing
- Audio feature extraction
- Emotion prediction
- Machine learning model training
